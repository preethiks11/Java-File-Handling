# Java-File-Handling
A Java Swing Notepad application demonstrating file handling, GUI components, menu operations, and text editing features.

## Features

* **New** – Clears the text area
* **Open** – Opens and reads an existing file
* **Save** – Saves changes to the current file
* **Save As** – Saves the content as a new file
* **Close** – Closes the application
* **Exit** – Exits the application
* **Cut** – Cuts selected text
* **Copy** – Copies selected text
* **Paste** – Pastes copied text
* **Select All** – Selects all text

## Technologies Used

* File Handling

* `JFrame`

## File Handling

The program uses:

* `FileInputStream`
* `FileOutputStream`
* `BufferedReader`
* `InputStreamReader`

These are used to read from and write text to files.
